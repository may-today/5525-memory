# 2026-08-05 封面标题版本徽章「星空漫游版」

## 目标

在封面页主标题「你的／时空旅行报告」上加一枚版本徽章「星空漫游版」。

## 实现

- `src/pages/CoverPage.tsx`：新增局部组件 `EditionBadge`，放在 `<h1>` 内（`h1` 改为 `relative`）。
  结构为「微星点层 + 四芒星 SVG + 文字」。
- `src/index.css`：新增 `.cover-edition-badge` 及相关类。
  - 深空蓝紫渐层底 + 内侧高光描边 + 投影，圆角胶囊。
  - 内部 5 枚 1px 径向渐变模拟不同星等的微星点，4.5s 缓慢明灭；四芒星错峰 -2.2s 同频闪烁。
  - `::after` 一道 6.5s 循环、只在前 45% 时间掠过一次的高光扫光。
  - `prefers-reduced-motion: reduce` 下全部关闭动画。
  - 文字用 `ChillDINGothic Std` 11px + 0.14em 字距，`text-indent` 补回末字后多出的一格空白。

## 两次返工

### 一：从「行内」改成「悬浮」

初版把徽章作为行内元素放在第一行「你的」之后，实际读起来变成
「你的 星空漫游版 时空旅行报告」，语义不连贯。

改为 `position: absolute` 脱离标题文字流，悬浮成一枚贴在标题上的贴纸。

**结论**：标题的修饰性 badge 不要参与文字流——中文标题没有空格分词，
行内 badge 会被连读成句子的一部分。

### 二：从「标题右上角」下移到贴住第二行

`top: -0.35rem` 把徽章顶在标题上缘，与标题之间隔了一整行的空白，
看起来是游离在标题之外的独立元素，而不是标题的一部分。

改为 `top: 1.9rem`：落在第一行「你的」右侧的留白里，底缘贴住第二行字身顶部，
被标题体块「兜住」。

**结论**：贴纸式装饰要落在主体的留白凹口里才会读作附着；
悬在主体外缘只会读作两个并列元素。

### 定位的两个约束

- **用 `top` 而非 `bottom` 锚定**：第一行恒为「你的」，第二行行盒起点固定在
  `1.125em`；而 `bottom` 锚定在窄屏（约 320px）下会出问题——「时空旅行报告」
  一旦折行，徽章会整个掉到第三行上。
- **`transform-origin: right center` + 倾角**：绕右侧旋转时左端会下沉约 8px，
  真正会先碰到「告」字头的是左下角而不是盒子底边。调 `top` 时要按左下角算，
  换倾角方向（`-5deg` ↔ `5deg`）也要重算。

## 亮度取舍

徽章整体亮度刻意压在白色主标题之下（文字 `#e4e4e7`、星点最高 0.7 透明度、
辉光只在投影里）。它是标题的注脚，不该成为第二个视觉焦点。
