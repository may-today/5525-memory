# 日志：护照首页地标网格 + 护照内页边框

日期：2026-08-05

## 出发点

用户反馈护照卡组首页「是纯文字的」，要求结合场次选择页已经在用的城市图。
`/form` 的城市折叠头用的是 `src/lib/city-icon.ts` 的地标 3D 小图（CDN 80×80 webp）。
核对本地 D1：`SELECT DISTINCT city FROM shows` 的 23 个城市名与 `cityImgIdMap` 的
23 个键完全一一对应，可以直接复用，不需要新增素材。

## 已落地

1. **城市纪念章网格**（`SummaryCardCity` 首页）：迷你圆章从「章内排城市名」改为
   「地标图坐在墨色圆框里 + 章下城市名」。未到场城市共用同一张图，灰度压暗成
   「压印了图案但还没上墨的凹版」。多场次城市在城名后带 Doto 场次数（>1 场才出现）。
2. **列数 5 → 6**：城名移到章外后每行多约 14px，实测 5 列 4 行会在 667px 高的
   小屏上把 MRZ 挤出内页框，6 列 4 行（6+6+6+5）刚好放下。
3. **护照内页边框**（首页 + 全部城市页）：外细线 + 四边斜纹防伪底纹 + 内细线 +
   骑在上框线上的页签。首页原来的 mono eyebrow 上提为页签，省下一行垂直空间。
4. `hasCityIcon()` 新增：城市名不在映射表内时退回纯文字圆章，不会请求
   `undefined.webp`。

## 决策与取舍

- **防伪底纹不用 `mask-composite`**：`mask-composite: exclude` 画环形带最直接，但
  Chrome 120 才支持标准语法，与既定的老 Android WebView 兼容边界冲突。改为同一份
  `repeating-linear-gradient` 重复四次 + `background-size`/`background-position`
  定位到四条边，全平台可用，四角重叠因为图案相同而不可见。
- **地标图不进城市页的大印章**：`2026-07-16` 计划已定「大章纯 SVG，不接图片素材」。
  首页是「集章册」，城市页是「章」本身——地标只出现在首页网格里。
- **砍掉套准十字**：曾计划在内页框四角加印刷套准十字，与斜纹防伪带同时出现过密。
  留防伪带（更贴护照），去掉十字。
- **场次数只在 >1 场时显示**：23 格里清一色的「1」是噪声，多场才是信息，
  与大印章「及另外 N 场」同口径。

`bun run typecheck`、`bun run lint`（10 个报错全部是既有的，落在未改动文件）、
`bun run build` 均通过。浏览器走查未做——本轮由用户自行在本地查看。
