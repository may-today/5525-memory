# 场次保存口令

- 2026-07-12：确定使用目录 index 的差分 ULEB128 + Base64URL；比为全量目录保留固定长度位图更适合少量选场次的常见情形，且第三方无需引入压缩库即可解码。
- 2026-07-12：实现 `/share` Sheet、复制反馈、稳定目录排序与公共编解码工具；README 已记录交互格式和还原校验。
- 2026-07-12：改用 `shows.id` 作为场次稳定序号（第 x 场），移除 `/share` 对全量场次目录的 loader 依赖；口令解码直接返回这些序号。
- 2026-07-12：分享页在客户端挂载后将本地持久化的 `showIds` 恢复至组件 state，避免 SSR 无法读取 localStorage 而让口令入口在刷新后保持置灰。
- 2026-07-12：移除 LEB128 差分编码，改为每场固定 2 字节 UInt16 + Base64URL；格式更直观，第三方仅需按两个字节读取一个场次序号。
- 2026-07-12：口令坐标改为按日期排序的零基 `showIndex`，不再使用未按时间排序的 `shows.id`；将 index 与已选场次一起持久化，分享页无需重取目录。
- 2026-07-12：移除固定两字节 Base64URL 格式，改为英文逗号分隔的十进制 `showIndex`，方便任何程序直接解析。
- 2026-07-12：改为自适应压缩格式；少量场次使用 LEB128 差分，密集选择使用位图，编码后比较长度取较短值。
