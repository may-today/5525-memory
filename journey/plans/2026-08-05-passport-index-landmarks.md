# 计划：护照首页引入城市地标图（复用 /form 的城市图标）

日期：2026-08-05（承接 `2026-07-16-city-passport-polish.md`）

## 背景

护照卡组首页（`SummaryCardCity` 的 index 0，「护照资料页」）目前完全由文字构成：
eyebrow → Doto 分数 `08 / 23` → 迷你圆章（章内只有城市名文字）→ MRZ 机读码。
23 枚圆章在深色底上是一片同质的小圆圈，只有文字大小的差别，缺少可辨认的视觉锚点，
也和后面每一张「一城一枚大印章」的城市页在信息密度上断层。

场次选择页 `/form` 的城市折叠头已经在用一套**城市地标 3D 小图**
（`src/lib/city-icon.ts` → `//mayday-replay-cdn.ddiu.site/5525/city/{id}.webp`，
80×80 透明 PNG/WebP，1–2KB，北京=角楼、新加坡=金沙、上海/台北等各有地标）。
本地 D1 的 23 个城市名与 `cityImgIdMap` 的 23 个键**完全一一对应**，可以直接复用，
不需要新增素材。

## 设计方案

### 签名元素：未上墨的凹版

同一张地标图承担两种状态，靠 CSS filter 区分，把「盖章」隐喻贯彻到收集网格：

- **已盖章**：地标原色，坐在子主题色（或跨主题的「彩虹印台」渐变）圆形章框里，
  带印色辉光 + 一层落在纸面上的投影。
- **未盖章**：同一枚地标退化为灰度压暗低透明——像护照上**压印了图案但还没上墨的凹版**，
  轮廓仍在、颜色未落。章框同步退化为灰色虚线。

这比「有图 / 没图」的二元处理更贴护照隐喻，也让「还差哪几座城」一眼可读，
且未到场城市不会变成纯粹的空洞。

### 版式：迷你圆章 → 纪念章 + 城名

单元格从「圆章内嵌文字」改为「圆章 + 章下城名」两段式：

```
 ╭─────╮ ╭─────╮ ╭─────╮ ╭─────╮ ╭─────╮
 │ 🏯  │ │ 🏙  │ │ 🌉  │ │ ▨   │ │ ▨   │     ← 圆形章框，微倾角，ink 描边 + 辉光
 ╰─────╯ ╰─────╯ ╰─────╯ ╰─────╯ ╰─────╯
  北京 3   上海 2   台北    厦门    天津       ← 城名（Doto 场次数仅在 >1 场时出现）
```

- 维持 5 列 × 5 行（23 枚）与既有的微倾角、错峰 pop-in，只有**章体**参与倾斜与动画，
  城名保持水平——歪的是章，不是标签。
- 城名移到章外后每行多约 11px；用三处收紧抵消，总高与当前版本持平（约 485px），
  不在小屏上产生新的溢出：
  - 分数与说明合并为一行基线对齐（`08 / 23  座城市已盖章`）；
  - 网格 gap 10px → 7px；
  - 网格与 MRZ 的上外边距 `mt-7`/`mt-8` → `mt-5`。
- 5 字以上的长城市名（拉斯维加斯）降一档字号，保证单行不越出单元格。
- 场次数只在该城去过 **2 场及以上**时显示，与大印章的「及另外 N 场」同一口径；
  23 格里清一色的「1」是噪声，多场才是信息。

### 保持不动

eyebrow、Doto 分数、MRZ 机读码：护照资料页的身份符号，是有意的文字排版，不是缺图。
城市页的大印章继续是纯 SVG（`2026-07-16` 计划的既定决策：大章不接图片素材），
地标图只出现在首页的收集网格里——首页是「集章册」，城市页是「章」本身。

## 改动文件

1. `src/lib/city-icon.ts` — 新增 `hasCityIcon(name)`；城市名不在映射表内时首页退回
   纯文字圆章，不会请求 `undefined.webp`。
2. `src/pages/summary/cards/SummaryCardCity.tsx` — 首页网格结构改为「章框 + 城名」，
   补 `data-visited` 到外层按钮、多场次计数、更完整的 aria-label。
3. `src/index.css` — `.city-mini-stamp` 由按钮降为章框、新增 `.city-mini-stamp-icon`
   与 `.city-passport-city*`，未盖章态改写为灰度凹版；reduced-motion 清单沿用。

## 追加：护照内页边框（实施中用户提出）

用户反馈「护照页整体有点极简，可以给每页添加一个契合主题的边框，看起来像护照本一样」。
每一页（首页与全部城市页）包进 `.city-passport-page` 内页框：

- 外细线 + 沿四边 7px 的 45° 斜纹**防伪底纹** + `inset: 7px` 的内细线。
- **页签**骑在上框线中点，用卡片底色截断框线：首页 `MAYDAY #5525 · TOUR PASSPORT`
  （原来的独立 eyebrow 上提至此，省下一行垂直空间），城市页 `PAGE + Doto 页码`。
- 墨色由每页的 `--page-ink` 驱动（首页蓝 / 城市页子主题色 / 未到场中性灰），
  横滑时框线随页换色，与既有的环境光同步。
- 防伪带用同一份斜纹重复四次 + `background-size`/`background-position` 定位到四条边，
  **不用 `mask-composite`**（Chrome 120 才支持标准语法，与老 Android WebView 的
  既定兼容边界冲突）。
- 内页框靠横向 `margin` 在相邻页之间留书缝，滚动容器 `items-center` → `items-stretch`
  让页框撑满卡片高度。

因为边框吃掉约 56px 垂直空间，网格列数一并由 5 改 6（4 行，6+6+6+5），
保证 667px 高的小屏上分数、网格与 MRZ 仍能一起放进框内。
