# 数据电台结尾曲分段

## 目标

为报告页歌曲工具新增 `section=ending`。它不依赖既有的 `section` 数据值，而是按每场歌单的最大 `sort_order` 取最后一首 `item_type='song'`，用于回答「我听过最多的结尾曲是什么？」等问题。

## 实施步骤

1. 扩展报告统计分段类型和受控工具 schema，接受 `ending`。
2. 在歌曲排行与单曲时间线查询中用同场次最大歌曲排序号筛选 `ending`，保留场次范围和时间过滤。
3. 更新工具/系统提示词，明确“结尾曲”必须传 `section=ending`，而“安可”仍使用 `encore`。
4. 用本地 D1 数据验证 ending 结果确为每场最后一首歌，并运行类型与静态检查。

## 边界

- `ending` 是虚拟统计分段，不改变 D1 schema 或既有歌单 `section` 数据。
- “最后一首歌”按歌曲行的 `sort_order` 判定；末尾若有非歌曲项目，不会把它当作结尾曲。
