# Summary 单次 D1 查询计划

## 目标

将 `getSummaryData` 从多条 D1 聚合查询改为一次读取全量非隐藏场次及其歌单数据，并在 server function 内存中计算既有统计指标。

## 实施步骤

1. 使用一条 `shows` 与 `setlist_items` 的联表查询获取统计所需的完整巡演快照。
2. 在服务端按用户选择的场次 ID 过滤并计算概览、歌曲、随机曲目和小众曲目统计，保持 `SummaryData` 响应契约不变。
3. 对比改造前后的本地 D1 结果，并运行类型检查与代码质量检查。

## 风险与取舍

- 单次读取会拉取整趟巡演的歌单行，适合当前约 270 场、约 1.5 万行的数据规模，能显著降低每次请求的 D1 statement 数。
- 不将原始歌单行返回浏览器，避免增大 RPC 响应；“本地计算”限定在 Worker/server function 内存中完成。
