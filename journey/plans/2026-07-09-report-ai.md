# Report AI Integration

## Goal

Make `/report` actually usable by replacing mock cards with TanStack AI powered structured report cards.

## Decisions

- The client does not expose a model selector.
- The server uses an OpenAI-compatible model configured by environment variables:
  `REPORT_AI_BASE_URL`, `REPORT_AI_API_KEY`, `REPORT_AI_MODEL`, and optional `REPORT_AI_PROVIDER_NAME`.
- v1 uses controlled D1-backed statistics tools plus AI card composition, not free-form SQL.
- The existing printed card visual stays; the "示例数据" badge is removed for real data.

## Implementation

- Add shared report schemas/types for card data and structured AI output.
- Add D1-backed report statistics helpers for attendance, city ranking, song ranking, song timeline, guests, and monthly/seasonal song ranking.
- Add `/api/report-chat` as a TanStack Start server route using `chat()`, OpenAI-compatible adapter, server tools, `outputSchema`, and SSE.
- Refactor `ReportPage` to use `useChat` with selected show IDs from local state/store and render structured-output parts as `ReportCard`.
- Update `journey/design.md` once the effective project state changes.

## Verification

- `bun run typecheck`
- `bun run build`
- Manual report flows with no selected shows, selected shows, suggestion chips, and free-form questions.
