# 场次保存口令

## 目标

将用户选中的场次编码为短、可逆、可跨程序实现的字符串，并在 `/share` 提供复制入口。

## 方案

- 场次序号使用所有可见场次按日期排列后的零基 `showIndex`，在表单加载目录时写入已选场次并持久化。
- 口令采用 `5525-` 前缀与自适应压缩：稀疏 index 使用 LEB128 差分、密集 index 使用位图，均以无填充 Base64URL 承载并取较短结果。
- `/share` 直接使用已选场次的序号；Sheet 显示并复制口令。
- README 公开二进制格式、边界校验与解码伪代码，供其他程序实现。

## 验证

- 对编解码工具做代表性 round-trip 与非法输入检查。
- 运行格式、类型检查及构建（若环境允许）。
