# 时长统计卡视觉重设计：「时之穹顶」（2026-07-11）

## 背景

首版「蓝色星轨沙漏」（`journey/plans/2026-07-11-duration-card.md`）功能可用，但用户反馈：

1. 沙漏造型太标准、太拟真，没有美感——要意象化，比如只露出上半部分、呈半圆状；
2. 缺少多巴胺 / 渐变背景元素；
3. 沙子流出后应**随即拼成文字**，而不是先在下球堆积、再整体汇聚成数字。

## 设计方案

### 造型：从「双球沙漏」到「时之穹顶」

- 粒子组成一个**半圆穹顶**（弧顶朝上、弦在下），悬在画面上部约 12%–34% 高度处——它是被抽象掉下半身的沙漏上球，弦就是隐含的漏颈水平线。
- 轮廓粒子只勾勒弧线（继承星轨语言）+ 少量散布在弦上；不再画拟真的玻璃收腰轮廓。
- 沙粒旅程合并为一段：**家 → 弦中点漏口 → 贝塞尔坠落 → 直接落位到数字点云**。数字随沙粒陆续落定逐渐成形（按数字点云 x 坐标微排序错峰，文字大致从左到右显影）；落定的沙粒继续闪烁，数字整体有微光呼吸。
- 下落段保留拖尾 ghost（星轨基因）；p≥0.93 淡出、DOM 数字淡入的交接机制不变。

### 背景：多巴胺弥散光

- hero 背景叠三团低透明度弥散光斑，颜色取**三个巡演子主题色**（5525 粉 `#f472b6`、5525+1 蓝 `#38bdf8`、5525+2 橙 `#fb923c`，与表单页主题一致）——多巴胺有主题依据，不是随意撞色。
- 粉在左上（近穹顶）、橙在右下、蓝静置在数字后方补辉光；粉/橙两团做 26–32s transform-only 慢漂移，`prefers-reduced-motion` 下静止。
- 透明度控制在 0.14–0.16 量级，深底和蓝色粒子仍然主导。

### 布局调整

- 数字文案块从 `top-[44%]` 下移到 `top-[58%]`，给「穹顶在上、沙落成字在下」留出坠落距离。
- 三阶段进度轴微调：flow 段拉长（0.14–0.86，坠落即拼字需要更长的错峰窗口），交接阈值不变。

## 不变的部分

滚动跑道 / scrub 可逆纯函数架构 / 时间基缓动 / sprite + `lighter` 渲染 / DPR≤1.5 / isPaused / 零状态与 reduced-motion 分支 / 列表区、数据口径全部不动。
