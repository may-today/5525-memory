# /share 分享页「星轨共振」宇宙航线海报

## 背景与目标

/share 是「时空旅行报告」主题的终点站，当前只有一块灰色占位预览区。目标是把它做成一张
用户看一眼就想收藏、愿意发朋友圈的「旅行纪念品」——走极简、高审美的艺术海报路线，
不堆砌数字，用一条发光星轨包容所有数据。

## 意象拆解（来自产品构思）

- **深空背景**：深邃宇宙 / 黑洞感，复用嘉宾卡的 `summary-space-*` 星点分层背景。
- **星群星座（签名元素）**：用户去过的所有场次串成一条发光星轨——每场是一个坐标点，
  按日期顺序连线，形成独一无二的星座。只去一场时退化为一颗「孤勇星球」，
  以扩散的引力波圆环表达。
- **音频声波图底**：海报下部用淡淡的确定性伪波形绘制「常驻曲」的声波。
- **吸睛金句**：「宇宙很大，但谢谢我们在 5525 号星域相撞。」

## 设计 Token（继承全站语言）

- **色**：`zinc-950` 深空底；节点用巡演子主题三色（5525 粉 `#f472b6`、+1 蓝 `#38bdf8`、
  +2 橙 `#fb923c`，未知回退 `themeColor`）；海报的「主导色」= 用户去过最多的子主题色，
  用于金句辉光与波形淡染——每个人的海报会因此有不同的色温。
- **字**：WJH 承担金句（情感语气）；Doto 点阵体承担数字（日期、场数）；
  Geist Mono 承担 eyebrow / 落款 / 序列号等档案性文字。
- **布局**：海报为固定比例（约 5:7）的画框，页面内垂直居中，四周留白；
  上：一行 eyebrow + 细线 → 中：星座 SVG（画幅主体）→ 下：波形 + 金句 → 底：数据落款一行。
- **序列号**：底部落款用场次口令（`5525-…`）作为限量编号 `NO.{passcode}`——
  口令本身由所选场次唯一决定，天然是「这张海报独一无二」的证据。

## 技术方案

- **数据**：复用 `useSummaryData()`（与 /summary 同一 server function），拿
  `selectedShows`（星座节点）、`randomSongStats.entries[0]`（常驻曲，缺失时回退
  `songStats.topSong` 并改文案为「你听过最多的歌」）、`overview`（场/城数）。
  hook 同时回填 store，口令入口逻辑保持不变。
- **星座布局（纯函数、确定性）**：场次按日期排序；x 按序号均匀铺开 + 以 show.id 做
  种子的 hash 抖动；y 在中带内 hash 抖动。连线用 Catmull-Rom 转三次贝塞尔的平滑曲线，
  `pathLength=1` + dashoffset 做 2.4s draw-in。节点标签 n>8 时抽样至 ≤8 个
  （永远保留首尾），上下交替避让。
- **孤勇星球**：n=1 时居中大节点 + 三圈 `share-gravity-ring` 扩散动画（transform-box:
  fill-box 的 scale/opacity），文案落款单场日期城市。
- **伪波形**：56 根竖条，高度 = hash(歌名字符, i) × sin 包络，中线镜像，低透明度主导色。
- **动画**（全部 transform/opacity/dashoffset，一次性或低频）：海报整体淡入 → 星轨
  draw-in → 节点错峰点亮后持续微 twinkle → 引力波扩散（单场）。`prefers-reduced-motion`
  下全部静态终态可见（reduced-motion 块里显式归位 dashoffset / opacity）。
- **零状态**：未选场次时海报保留星空 + 居中文案「你的星域还一片寂静」，引导回 /form。
- **加载态**：`ready` 前显示居中脉冲文案「正在绘制你的星域…」。
- **保存图片 / 分享按钮**：维持 disabled（html2canvas 评估仍在后续工作清单）。

## 风险与取舍

- 星座 x 按序号（非真实时间距离）铺开：14 场跨三年的真实时间轴会让节点挤成几团，
  等距 + 抖动在海报语境里更均衡美观；日期信息由节点标签承担。
- 口令做序列号只是视觉引用，复制入口仍在「将场次保存到...」Sheet；过长时省略号截断。
