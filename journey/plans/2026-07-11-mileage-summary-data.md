# 奔波距离统计接入计划

## 目标

将表单保存的地点信息随 `/summary` 请求传入 `getSummaryData`，由服务端复用既有 `getDistance` 计算用户到每个已去过城市的往返距离总和，并返回给统计页面数据契约。

## 实施步骤

1. 扩展统计 server function 的请求数据与响应数据，校验可选坐标并声明奔波距离的空值语义。
2. 按已选场次的城市去重，使用服务端城市经纬度和定位坐标计算每座城市的单程距离乘二后求和。
3. 让 summary hook 从 store 或 localStorage 恢复定位信息并一并提交；更新设计文档和过程日志。
4. 运行格式、类型与静态检查，确认没有多余变更。

## 口径

- 优先使用浏览器定位坐标；用户未授权、清除定位或坐标非法时，回退使用表单选择的城市／地区中心坐标；两者皆不可用时，`mileage` 返回 `null`。
- 同一城市的多场演出只计一次往返，因为统计对象是「去过的各城市」。
- 没有服务端城市坐标映射的城市不计入，避免以猜测坐标产生距离。
