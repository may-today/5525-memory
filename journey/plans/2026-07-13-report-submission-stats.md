# 匿名报告登记与同场统计

## 目标

在用户完成场次选择、进入生成流程前，以可幂等的方式登记匿名报告，并在统计页展示稳定的报告序号与各已选场次的同场报告人数。

## 设计

- 新增一张报告主表和一张报告—场次关联表；不保存昵称、城市或定位。
- 浏览器为一次报告持久化 UUID；同 UUID 的重试不会增加报告数或重复关联场次。
- 服务器验证场次均为可见场次，使用 D1 `batch()` 原子写入主记录与所有关联记录；登记在 loading / summary 页面后台以同一 UUID 退避重试，不阻塞进入生成页。
- 名次采用主表整数主键，代表数据库实际接受登记的先后顺序；同场人数可稍后读取，不要求跨地域读取即时一致。

## 实施步骤

1. 新增 D1 migration 与索引。
2. 实现带输入校验、幂等写入和同场聚合查询的 POST server function。
3. 在表单开放后的提交动作中登记并重试；把结果持久化到浏览器 store。
4. 在概览卡展示报告序号与同场同行者统计。
5. 应用本地 migration，执行类型检查和代码检查。
