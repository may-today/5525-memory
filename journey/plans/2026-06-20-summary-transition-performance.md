# 统计页切换性能优化计划

## 问题

`contribution-graph` 与 WebGL 地球相邻切换时出现明显掉帧。旧页在过渡阶段被重新挂载，时间轴产生高频全量 SVG 协调，地球卸载后 RAF 循环未停止。

## 方案

1. 使用稳定的页面索引 key 保留退出页实例，避免过渡开始时重启重型组件。
2. 将时间轴逐场 state 更新改成等时长的批量更新，减少 React render 次数。
3. 取消地球卸载后的 RAF，并限制高分屏像素比和采样成本。
4. 将切页层提升为独立合成层，限制布局与绘制影响范围。
5. 运行 lint、typecheck 和 production build 验证。

## 约束

- 保持现有页面顺序、视觉内容和 0.7 秒无缝切页动画。
- 不改变用户选择数据与统计逻辑。
