# 表单页场次口令导入

## 目标

让用户在 `/form` 的场次选择步骤粘贴分享页生成的 `5525-` 口令，并以解析出的场次完整替换当前选择。

## 设计

- 复用 `src/lib/show-passcode.ts` 的既有解码协议，保持与分享页完全兼容。
- 在场次选择步骤提供底部 Sheet：输入口令并确认导入。
- 解码后以已加载的 `showIndex` 映射场次；空口令、格式错误、或包含当前目录未收录索引时不修改现有选择。
- 成功导入时清除与旧选择绑定的匿名报告登记，持久化新选择，并展开对应城市；用户资料不受影响。

## 实施步骤

1. 为 store 新增原子替换场次选择的方法。
2. 在表单第二步加入导入口令 UI 与解析、目录校验、替换反馈。
3. 运行类型检查与代码检查，并记录结果。
