# 报告页「你的专属报告」效果图

## 目标

新增 `/report` 页面：一个 agent 聊天界面，用户输入感兴趣的统计项（如「秋天我听过最多的歌」），
经过一段「计算中」的演出后，返回一张精致的数据卡片。本期只做效果图（mock 交互 + 假数据），
不接入真实 AI / 统计逻辑。对应 design.md 待办「评估在统计数据之上接入 AI 自然语言查询能力」。

## 设计方案

- **意象**：「5525 数据电台」——你发出一条询问电波，电台检索你的巡演记录，打印出一张数据凭证。
- **视觉**：延续 summary 的深空视觉（zinc-950、星点背景、场次 themeColor 辉光）；
  卡片大数字用项目已有的 Doto 点阵字体（`font-geist`），标题用 WJH（`font-wjh`），正文 Geist Mono。
- **签名元素**：结果卡片以「热敏打印」方式自上而下显现（clip-path reveal），
  像电台打印出一张属于你的数据小票。这是页面唯一的重动画，其余保持克制。
- **图表**：卡片内的排行为单色系横向条（accent 主题色、圆角端点、直接标注），
  文字用 ink 色而非条色，符合 dataviz 规范；单系列不设图例。

## 交互流程（全部 mock）

1. 进场：agent 欢迎语 + 3 个建议问题 chips。
2. 用户点 chip 或自由输入 → 追加用户消息。
3. agent 显示逐条点亮的「思考步骤」（检索记录 → 聚合统计 → 生成卡片，约 2.5s）。
4. 步骤完成后追加卡片消息，打印动画显现；chips 保留可继续提问。
5. 自由输入时按顺序轮换 3 套预设卡片数据。

## 卡片变体（假数据）

1. 秋天听过最多的歌：主答案《突然好想你》×6 + Top5 排行条。
2. 看过最多场的城市：主答案 上海 ×4 + 城市排行条。
3. 单曲累计次数（《温柔》）：主答案大数字 5 + 场次日期时间线。

每张卡片含：眉题 + 流水号（REPORT №00X）、复述的问题标题、主答案、图表区、
数据口径脚注（虚线小票分隔），角落标注「示例数据」。
