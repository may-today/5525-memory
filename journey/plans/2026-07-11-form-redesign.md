# 表单页视觉重设计（2026-07-11）

## 背景

`/form` 目前是功能性默认样式：普通标题 + 普通输入框 + 普通手风琴，与封面页/预热页的编辑排版语言（分区边框、eyebrow、Doto 点阵数字、品牌橙）以及 summary 各卡「themeColor 驱动视觉」的语言脱节。

## 概念：时空旅行登记

整个应用的叙事是「你的时空旅行报告」，表单就是登机前的**旅程登记**：

- 第一步登记旅客（PASSENGER）——称呼与出发地；
- 第二步登记时间坐标（TIME COORDINATES)——回到哪几天。

城市按首演日期排序本来就是巡演路线，用 Doto「站号」编码这条真实时间线；每场演出的选中态用**该场次自己的 themeColor** 点亮，与 summary 卡片一脉相承。

## 设计令牌

- **色**：背景/边框沿用全局 zinc 体系；品牌橙 `#f97316` 只用于「聚合选中数」（城市徽标、底栏已选数、步骤进度）；单场选中态用场次 `themeColor`。
- **字**：H1 用 `font-title`（ChillDIN），步骤号/站号/已选数用 `font-geist`（Doto），日期 `tabular-nums`。
- **签名元素**：场次行勾选后被自己的 themeColor 点亮——左侧色条 + 复选块填色发光 + 行背景轻染 + 子主题标签同色。一页勾下来像一排亮起的荧光棒。

## 布局

```text
┌──────────────────────────────┐
│ TIME COORDINATES     02 / 02 │  eyebrow + Doto 步骤号
│ 你去过哪几场？                │  font-title H1
│ 按巡演时间线排列 · 12城 43场  │  真实信息副标
│ ▓▓▓▓▓▓▓▓ ▓▓▓▓▓▓▓▓          │  两段步骤进度（当前段橙色）
├──────────────────────────────┤
│ 01 北京 · 共6场      [2]  ▾  │  Doto 站号 + 橙色选中数徽标
│ │▌■ 2023.05.26  回到1999 FRI │  选中行：themeColor 点亮
│ │ ☐ 2023.05.27  …        SAT │
├──────────────────────────────┤
│ 已选 2 场 · 1 座城市     清空 │  数字 Doto + 橙辉光
│ [ 下一步 ]                    │
└──────────────────────────────┘
```

## 动效（全部 opacity/transform，遵守 reduced-motion）

- 步骤切换：整页内容 `form-step-in`（淡入 + 12px 上移，root div 用 `key={step}` 强制重挂载）。
- 城市展开：场次行容器 `form-rows-in` 轻淡入；chevron 旋转过渡。
- 选中态：颜色/辉光均为 0.2s transition。

## 文案

- 步骤一：eyebrow `PASSENGER`、H1「出发之前，先认识你」；城市字段改为「你从哪里出发？（可选）」，提示语「用于计算你的奔波距离」——呼应城市卡「那一天，你从X出发」的文案。
- 步骤二：eyebrow `TIME COORDINATES`、H1「你去过哪几场？」，副标带真实城市/场次总数。
- 底栏：「已选 N 场 · M 座城市」。

## 不做的事

- 不改任何数据流、store 逻辑、路由与 gate 行为。
- 不换手风琴交互（已有 UX 决策）。
- 不加背景纹理/大面积装饰——克制，把「亮」留给 themeColor 选中行。
