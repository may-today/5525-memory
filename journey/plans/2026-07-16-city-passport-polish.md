# 计划：城市护照卡 UI 精修 + 护照首页总览

日期：2026-07-16（承接 `2026-07-16-city-passport-redesign.md`，该计划的基础实现已落地）

## 背景

护照卡组（横滑一城一章）已实现基本功能：SVG 印章、邮戳日期条、dots 导航。用户反馈两点：

1. 界面需要进一步精修——「精美、有设计感」。
2. 在卡组**首页**补充一张所有城市的汇总页。

「首页」理解为横滑卡组的第一页（护照资料页），而非应用封面路由 `/`——封面页是编辑排版
语言的入口页，不承载统计内容；护照隐喻下「翻开第一页看到全部印章缩览」也更自然。

维持既定决策：不接入图片素材（`src/data/stadium.ts` 已存在但保持未引用），纯 CSS/SVG。

## 设计方案

**签名元素：盖章瞬间**。城市页首次滑入视口时，已到场城市的印章以「盖下去」的动画入场
（scale 1.45→1 + 回转到自身微倾角 + 透明度 0→1，overshoot 缓动），邮戳日期条延迟 0.45s
滑入——把「护照被盖章」这个动作本身变成卡片的记忆点。reduced-motion 下直接静态显示。

### 1. 护照首页（卡组 index 0）

- 竖排居中：mono eyebrow `MAYDAY #5525 · TOUR PASSPORT` → Doto 大字分数 `08 / 23`
  （已盖章数白色发光、总数灰）→ 迷你印章网格 → 底部 MRZ 机读码。
- **迷你印章网格**：5 列圆形迷你章，一城一枚；到场 = 子主题色实线描边 + 低透明填充 +
  辉光，未到场 = 灰色虚线空心；每枚带 ±3° 内的微倾角（真实护照印章从不端正）；
  点按跳转到对应城市页。挂载时按 `--i` 错峰 pop-in。
- **MRZ 机读码**（护照资料页的身份符号）：两行 mono 低透明 `<` 填充串，内容为真实数据
  （巡演名 / 已盖章数 / 总城市数 / 里程），非装饰性乱码。

### 2. 城市印章精修

- **微倾角**：每枚印章按 index 取 ±4° 内的固定倾角（`--stamp-rotation`），邮戳随章体一起倾斜。
- **章体层次**：文字环外新增细外圈（r=92）+ 机刻细密刻线圈（r=87，dasharray 细点），
  更接近真实橡皮章的双圈结构；未到场态同样退化为灰色。
- **印泥不匀**：到场章整体叠 radial-gradient mask（复用小众歌单卡「仅此一次」印章的
  缺墨手法），静态 mask 叠在旋转文字环上反而更像固定光照下的真实油墨。
- **盖章动画**：见签名元素；未被激活过的到场章保持透明，由 IntersectionObserver 的
  activeIndex 首次命中时加 `data-stamped` 触发一次性动画。
- **环境色**：卡片背景叠一层极低透明度（10%）的 radial 环境光，颜色随当前页印章的
  子主题色渐变过渡（`@property` 注册 `--city-ambient` 实现 color transition；老浏览器
  退化为瞬时切换）。

### 3. 页头与信息行

- 页头维持与其他卡一致的 `font-title text-xl` 标题；叙事句中的城市数 / 公里数改用
  `.overview-count`（Doto 700）强调，与时间轴卡计数语汇统一。
- dots：新增首页专属「书页」形指示（圆角短矩形）；城市 dots 按子主题色着色
  （`--dot-color`），未到场保持灰。

## 追加：彩虹印台渐变墨色（实施中经用户确认）

实测本地 D1：23 城中 10 城跨多个子主题（北京/台北跨全部三段，上海/台中等跨两段），
单一代表色抹掉了这层信息。经用户确认采用**渐变墨色**方案（现实中存在「彩虹印台」，
隐喻成立）：

- `CityMarker` 新增 `subThemes: string[]`（该城市全部场次去重子主题，按首次出现序，
  过滤空值脏数据——香港有一场 `sub_theme` 为空）。
- 客户端按 粉→蓝→橙 固定色序排列后映射为 SVG `linearGradient`，经 `--stamp-ink`
  传入 CSS（`url(#…)` 或纯色），描边/环形文字/章体共用；辉光、邮戳、dots、迷你章
  描边取首色；迷你章底色用同一渐变。未盖章城市仍为灰色（渐变只在盖章态可见）。

## 追加：走查中发现并修复的问题

1. **Chrome smooth 滚动被 scroll-snap mandatory 中途取消**：原生 `scrollIntoView`/
   `scrollTo({behavior:'smooth'})` 在该容器上会停在非 snap 位置（实测 328.5/877.5px），
   属既有问题；`scrollToIndex` 改为 RAF 自绘 ease-out + 动画期临时关 snap。
2. **邮戳盖住城市名**：邮戳条原先定位在印章正中，与居中城市名完全重叠（既有问题）；
   移到 66% 高度斜穿下部。
3. **dots 行与容器悬浮「滑动探索」引导重叠**：dots 行 `pb-8` → `pb-20` 让位。
4. **未盖章城市环境光**：不再取代表场次主题色，改为中性灰（灰章无光）。
