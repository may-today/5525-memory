# 最小众歌单改用全巡演总演唱次数

## 目标

修正「最小众歌单」的冷门判断：候选歌仍是用户在点歌／安可随机段落实际听到的五月天歌曲，但全巡演频次改为该歌在所有歌曲段落的总演唱次数，避免歌曲在某场随机出现、却在其他场次作为固定曲高频演出时被误判为冷门。

## 实施

- 在 `buildRareSongStats` 中分别聚合随机候选曲目与全巡演全部五月天歌曲。
- 用后者填充 `tourCount`，并保持现有排序、主纸条例外与小纸条 `<= 8` 门槛。
- 同步类型注释、卡片口径与项目设计记忆。

## 验证

- 运行 `bun run typecheck`。
- 运行 `bun run lint`。
