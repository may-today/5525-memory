# 回忆卡真实数据接入

## 目标

将 `special-event` 中维护的场次回忆渲染到 `/summary` 的「你的回忆」卡。默认显示用户参加场次命中的专属回忆；若没有命中项则显示全部回忆，并允许在两种范围之间切换。

## 实施步骤

1. 以当前 `Show.showDate` 适配旧的回忆分组逻辑，保留跨日回忆的去重规则。
2. 将条目从逐场占位改为逐条真实回忆：CDN 封面、`title` 描述，以及暂存的 talking 占位。
3. 在头部加入专属／全部切换，专属为空时回退到全部列表。
4. 更新设计文档与日志，并运行 lint、类型检查和差异检查。

## 结果

- 已完成四项步骤；`bun run typecheck`、`bun run lint` 与 `git diff --check` 均通过。
