# 最小众歌单卡：被抽中的点歌纸条（SummaryCardRareSongs）

## 背景与目标

「专属歌单」卡（04）统计随机曲目里听过最多的常驻曲。本卡是它的镜像：统计用户**听过次数最少**的随机曲目——那些全巡演没唱过几次、偏偏被用户撞见的冷门歌。设计要求与其他统计卡一致：实体纪念品意象承载数据，不做冷冰冰的图表页（见 memory `summary-cards-feel-like-keepsakes`）。

## 意象选择：点歌纸条

- 点歌环节的歌本来就来自歌迷写下的纸条，「被抽中的纸条」与「随机曲目」语义完全同构；全巡演只被唱过一次的歌，就是只被抽中过一次的纸条。
- **放弃拍立得方案**：一次成像/无底片与「仅此一次」很贴，但「你的回忆」卡（原 06）已经使用照片框意象，同一副卡组里出现两张照片卡会重复。
- **放弃磁带 / SIDE B 方案**：紧跟在黑胶卡后再来一件旋转音频介质，意象同族且相邻，喧宾夺主。

## 数据口径

- 随机曲目条件与专属歌单卡一致：`item_type = 'song' AND (section = 'request' OR section LIKE 'encore_%')`。
- 排序：用户听到次数 `heardCount` 升序 → 全巡演出现次数 `tourCount` 升序 → 标题，保证 SSR 稳定；取前 7 首（1 张主纸条 + 6 张小纸条）。
- `tourCount` 基于全部非隐藏场次统计（本地数据验证：45 首随机曲目全巡演只唱过 1 次，「仅此一次」的叙事成立）。
- **小众门槛（实现中补充）**：小纸条要求 `tourCount <= 8`（约 5% 场次）；否则单场用户（人人 heardCount = 1）会把《顽固》这类全巡演 ×30+ 的常驻曲当成冷门曲展示。主纸条不受门槛限制，文案按 tourCount 自适应。
- 每首歌关联用户**第一次听到它**的场次（城市 + 日期），作为纸条上的落款。

## 设计方案

### 布局（移动端优先，纵向滚动）

```text
05 / 最小众歌单
全巡演最少被唱起的歌，偏偏被你撞见了。   ← 眉标 + 标题（shrink-0）
────────────────────────────────
        （顶部一束暖色追光，淡淡打在主纸条上）
        你的沧海遗珠
        ╭─────────────────╮
        │ ▒ 和纸胶带         │        ← 主纸条：微倾斜的暖白纸片
        │  点歌纸条 · 城市 日期 │
        │  《歌名》(WJH 手写感) │
        │            ⊙仅此一次 │        ← tourCount=1 时的橙色印章
        ╰─────────────────╯
        全巡演 163 场，它只响起过这一次——而你，就在台下。

  同样被你收藏的冷门曲 · N 首
  ┌────────┐ ┌────────┐
  │小纸条 歌名 │ │小纸条 歌名 │      ← 2 列小纸条，交替 ± 微旋转
  │城市·全巡演×2│ │城市·全巡演×1│
  └────────┘ └────────┘
  没被唱够的歌，才最像秘密。……          ← 收尾句 + 口径注脚
```

### 纸条构成（纯 CSS）

- **纸面**：暖白线性渐变 + 两道极淡的横向折痕阴影（被展开的三折纸条），深暖墨色文字；歌名用 `font-wjh` 承担手写感。
- **和纸胶带**：主纸条顶部一小段半透明品牌橙胶带，轻微斜置。
- **印章**：`tourCount === 1` 时右下角一枚旋转的橙色圆形描边章「仅此一次」；非唯一时省略。
- **追光**：卡片顶部一层静态 radial-gradient 暖光锥，营造「散场后从纸箱里抽出一张」的舞台感。
- **动画**：纸条逐张「飘落入位」（translateY + 旋转过冲收敛 + 淡入，`--i` 错峰），追光先淡入。`prefers-reduced-motion` 全部停用。
