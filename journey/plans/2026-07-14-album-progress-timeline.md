# 专辑解锁进度卡「创作年表」重设计

## 背景与目标

现有 `SummaryCardAlbumProgress` 是纵向卡片列表（封面 + 进度条 + 逐首胶囊），功能完善但是纯数据报表形态，与其他卡片的叙事化设计语言脱节。用户明确的方向：

- 简洁风；
- 一根线从左到右连接九张专辑；
- 用数字和文案，配合精美意象展示解锁进度；
- 可选配合视差滚动等技巧。

## 设计概念：创作年表 × 显影

九张正式专辑天然是一条时间线：1999《第一张创作专辑》→ 2016《自传》。这条线不是装饰，而是乐队十七年的创作年表——起点是「第一张」，终点literally叫「自传」，叙事自洽。

**签名元素：封面显影。** 解锁进度不再用进度条表达，而是映射到专辑封面本身的色彩——没听过一首的专辑是灰阶暗片，随听过比例升高逐渐「被听回颜色」，100% 时满色 + 辉光。「解锁成你的五月天」= 你的现场经历给他们的作品上色。

## 布局

单屏卡片（复用嘉宾星球卡先例：无 `data-scroll-container`，主体为横向滚动条带，横滑不会误触发纵向切页）：

```
┌──────────────────────────────┐
│ 标题：九张专辑，解锁成你的五月天。 │
│ 引导语（总数、你已听 N 首、暗示往右滑）│
│                              │
│   [1999]   ghost年份          │
│   ▣封面 专辑名 已听x/y   ▣    │  ← 奇数站在线上方
│ ──●────────●────────●──→    │  ← 时间线（挂载时从左向右 draw-in）
│    1999     ▣封面...  2001   │  ← 偶数站在线下方，年份标签在对侧
│                              │
│ 口径注脚                      │
└──────────────────────────────┘
```

- 站点交替上下，形成时间线的波浪节奏；每站：巨大 ghost 年份（Doto、低透明度、横向视差）垫底，封面（88px，显影滤镜）、专辑名（font-title）、`已听 x / y`（Doto）、连接线上节点。
- 时间线是纯 CSS 伪元素 hairline，节点三态：0% 暗点 / 部分点亮 / 100% 满色辉光。
- 横向滚动复用 `summary-space-scroller`（隐藏滚动条 + 两侧渐隐）。

## 动效

1. 挂载：时间线 `scaleX` 从 0 → 1（origin-left，~1.2s），站点按 `--i` 错峰淡入上移；
2. 显影：站点入场后封面从 `grayscale(1)` 过渡到各自进度滤镜（transition + 按 `--i` 错峰 delay），一次性演出；
3. 视差：横向滚动时 rAF 把每站相对视口中心的偏移写入 `--tl-par`，ghost 年份以不同系数 `translateX`，transform-only（复用回忆卡模式）；
4. `prefers-reduced-motion`：draw-in / 入场 / 显影过渡全部停用，静态终态直接可见；组件侧不挂滚动监听。

## 配色与字体

- 底色 `zinc-950`；线与未点亮元素 white/10~15；卡片强调色沿用 sky-400（只用于已听数字与满解锁节点）；封面自身色彩承担主要视觉。
- 标题 font-title；年份与数字 Doto（`.font-geist`）；正文默认。

## 数据口径（不变）

分母 = `songList` 中 `meta.album` 属九张正式专辑的曲目；分子 = 同标题 `tourSongs` 任一 appearance `isHeard`。年份取自曲库 meta。逐首胶囊标签移除——单曲粒度已由岁月留声机卡（脊线 + 唱片详情）完整覆盖，本卡收敛为专辑粒度的年表。

## 零状态

未听任何歌时年表仍完整呈现（全灰阶），引导语换为「选好你去过的场次，这条年表才会开始显影」。
