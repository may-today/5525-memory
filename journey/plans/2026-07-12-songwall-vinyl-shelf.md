# 岁月音乐墙 → 「岁月留声机」黑胶唱片架重设计

## 背景

`SummaryCardSongWall` 当前是扁平的砖块墙（tile 网格），信息完整但缺少情感意象。本次按「岁月留声机」概念重构：主视觉为一个复古木质唱片架，整齐排列 170+ 张黑胶唱片（以唱片封套脊线视角呈现），听过的唱片从架上「抽出来」并点亮。

## 视觉方案

### 意象与布局

- **主视觉**：深色胡桃木唱片架（CSS 渐变木纹框架 + 每行架板），架内暗色内腔，唱片以竖直脊线（sleeve spine）形式排列，脊线上用 `writing-mode: vertical-rl` 微缩竖排歌名（CJK 直立，Latin 旋转）。
- **上层架（多行）**：五月天曲库 171 首。排序 = `song-list.ts` 原始顺序中「本巡演唱过」的曲目在前，**全巡演未唱过的灰暗唱片排在最后**（用户指定）。
- **下层架（一行）**：曲库外惊喜曲目，**金色唱片**，单行横向滚动（复用嘉宾卡 `summary-space-scroller` 的隐藏滚动条 + 两侧 mask 渐隐模式，横滚不与纵向切页手势冲突）。
- 网格：`repeat(auto-fill, minmax(...))` 自适应列数；行高固定，架板由容器 `repeating-linear-gradient` 按行高绘制（无需按行切分数据）。

### 唱片状态（签名元素）

| 状态 | 表现 |
| --- | --- |
| 你听过（mayday） | 脊线以本卡专属紫 `#a78bfa` 点亮 + 辉光，`translateY` 从架内向上抽出，错峰依次弹出 |
| 演唱过没赶上 | 暗色脊线沉在架内，歌名弱化 |
| 全巡演未唱 | 更灰暗、低饱和的脊线，排在上层架最后 |
| 惊喜曲目 | 金色脊线（听过 = 亮金抽出 + 金辉光；没赶上 = 暗金沉底） |

### 动效

- 挂载后延迟 ~400ms，听过的唱片按架上顺序以 ~35ms/张 错峰「抽出」（translateY 过冲收敛 + 辉光淡入），全部 transform/opacity。
- `prefers-reduced-motion`：动画停用，听过的唱片静态保持抽出 + 辉光（静态即可辨识）。

### 文案

- 标题改为「曲库内外，这是你的 5525 岁月留声机。」保留原引导语数字句，追加一句「听过的唱片，已经替你从架上抽了出来」。图例、收尾句、口径注脚沿用原语义。
